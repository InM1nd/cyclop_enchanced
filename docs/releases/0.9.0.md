Лимиты без паролей и обновление из настроек.

**Keychain больше не спрашивает пароль.** Токены Claude и Cursor читаются
через `security`, который уже есть в списке доступа у этих записей. Диалог
«Cyclop хочет использовать связку ключей» при каждом взгляде на лимиты ушёл.

**Codex показывает честные цифры.** Окно, срок которого уже прошёл, больше не
висит со старым процентом — показывается 0 и новое время сброса. Строки без
окон (premium) пропускаются.

**OpenCode, Claude, Cursor офлайн.** Без сети остаются последние известные
цифры, кэш токена не стирается.

**Обновление из настроек.** Настройки → Основное → «Проверить обновления».
Новая версия скачивается с GitHub и ставится, только если подписана тем же
сертификатом, что и установленная. Иначе — кнопка «Скачать с GitHub».
