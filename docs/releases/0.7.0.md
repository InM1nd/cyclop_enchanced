Вкладка Memory и то, что вокруг неё накопилось в форке: idle-экран, модули
рельсов, пипетка, OpenCode.

**Давление памяти, как в «Мониторинге системы».** График на вкладке зелёный /
жёлтый / красный — тот же jetsam. Вырез при этом не копирует жёлтый: на 16 ГБ
это обычный рабочий фон. Светится только красный. По желанию — ещё и от
процента занятой RAM (выкл. по умолчанию, пороги 90 / 95). Ниже графика —
очистка безопасных кэшей; часть пунктов просит полный доступ к диску.

**Вырез не орёт по делу.** Приоритет ободка: превью из настроек, созвон
(за 10 минут), красная память, помодоро. Жёлтая память на островок не
попадает.

**Idle, модули, пипетка.** Полноэкранные ASCII-заставки из меню и глазка в
шапке. На правом рельсе можно прятать вкладки и ставить пресеты Work / Call /
Minimal. Пипетка копирует HEX с экрана.

**Usage.** Карточки Claude, Codex, Cursor и OpenCode — какие включены в
настройках. Три провайдера остаются в один ряд, четыре складываются 2×2.

**Заметки и календарь.** Todo-списки рядом с обычными заметками. У встречи —
когда выходить, если в событии есть место.

Компактные настройки живут в вырезе; полное окно — «Все настройки…» или ⌘,.
Вырез при этом сворачивается, чтобы было видно превью свечения.
